# 🖼️ Android Image Processing & Media Handler

[![Java](https://img.shields.io/badge/Java-Android-ED8B00.svg?logo=openjdk&logoColor=white)](https://www.oracle.com/java/)
[![Image Processing](https://img.shields.io/badge/Media-Bitmap%20Processing-00BCD4.svg?logo=google-photos&logoColor=white)](https://developer.android.com/topic/performance/graphics)

A specialized Android application demonstrating camera bitmap capture, gallery media selection, dynamic image scaling, and memory-safe image processing pipelines.

---

## 📸 Capabilities
- **Camera & Gallery Handlers:** Unified image selection from device storage or direct camera photo snaps.
- **Memory Optimization:** Efficient bitmap subsampling and scaling to prevent `OutOfMemoryError` on high-resolution photos.
- **Interactive UI:** Smooth image previews and responsive touch layouts.

---

## 🛠️ Tech Stack
- **Language:** Java
- **Platform:** Android SDK
- **Key Classes:** `BitmapFactory`, `Bitmap`, `ImageView`, `Intent`
- **Build System:** Gradle
